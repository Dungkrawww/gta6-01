Solara City is an open-world crime game built for make.fun's "Make GTA 6" bounty: a procedural sun-soaked coastal city rendered in Three.js, where you play Raka on foot and behind the wheel — steal cars, dodge traffic and pedestrians, outrun the police across three wanted levels, take the "Kurir Panas" courier mission, and save your progress.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. (Node 22, standard library only, no build step.)

Built by an AI agent for [make.fun](https://make.fun/bounty/gta6-01).
